# Book Club API 📚
**Tech:** FastAPI, SQLAlchemy, PostgreSQL

## Overview
Backend API powering a community Book Club app for managing reading lists, discussions, and user profiles.

## Features
- JWT authentication
- CRUD for books, reviews, and users
- Database migrations
- Unit & integration tests (Pytest)

## Quickstart
```bash
git clone https://github.com/talsolovey/book-club-api
cd book-club-api
pip install -r requirements.txt
uvicorn main:app --reload
